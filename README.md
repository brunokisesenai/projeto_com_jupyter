Projeto Final – Sistema de Análise de Vendas

1. Sobre o Projeto

Este projeto tem como objetivo realizar uma análise exploratória e estratégica de dados de vendas de uma empresa do setor varejista, utilizando Python para transformar dados brutos em informações relevantes para a tomada de decisões.

A partir de uma base de dados com 50.000 registros de itens vendidos, foram desenvolvidas análises para compreender o desempenho financeiro e operacional da empresa, identificar padrões de consumo, avaliar o desempenho dos vendedores e investigar oportunidades de crescimento.

O projeto faz parte de uma atividade prática de análise de dados, envolvendo as etapas de exploração, tratamento, manipulação e visualização de informações.

2. Objetivos

Realizar a exploração inicial e o tratamento da base de dados.

Identificar e corrigir inconsistências, valores ausentes e registros duplicados.

Calcular o faturamento bruto e líquido da empresa.

Identificar os produtos mais vendidos.

Analisar o desempenho financeiro das categorias de produtos.

Investigar a evolução das vendas ao longo dos meses e anos.

Avaliar o desempenho dos cinco melhores vendedores.

Analisar as preferências dos clientes em relação às formas de pagamento.

Comparar o desempenho comercial entre os estados brasileiros.

Desenvolver gráficos para facilitar a interpretação dos resultados.

Elaborar uma análise estratégica para identificar oportunidades de crescimento e orientar futuras ações de marketing.

3. Tecnologias e Bibliotecas Utilizadas

O projeto foi desenvolvido utilizando as seguintes ferramentas:

Python: linguagem de programação utilizada no desenvolvimento das análises.

Pandas: manipulação, organização, limpeza e análise dos dados.

NumPy: operações numéricas e apoio ao processamento dos dados.

Matplotlib: criação de gráficos e visualizações.

Jupyter Notebook: ambiente utilizado para desenvolver e documentar as análises.

4. Base de Dados

O arquivo utilizado no projeto é vendas.csv, contendo 50.000 registros de itens vendidos, distribuídos em 15 colunas.

A base apresenta informações sobre:

Identificação dos pedidos e itens vendidos.

Datas das vendas.

Produtos e categorias.

Quantidades e preços unitários.

Descontos e valores totais.

Dados dos clientes e localização geográfica.

Vendedores responsáveis pelas vendas.

Formas de pagamento.

Status das transações.

O arquivo utiliza o formato CSV, com campos separados por ponto e vírgula (;) e codificação UTF-8.

5. Etapas da Análise

O desenvolvimento do projeto foi dividido nas seguintes etapas:

5.1. Exploração e Tratamento dos Dados

Análise da estrutura da base, identificação dos tipos de dados, verificação de valores ausentes, registros duplicados e inconsistências nas informações.

5.2. Análise Financeira

Cálculo do faturamento bruto e líquido, considerando os descontos e os status das vendas, para avaliar o desempenho financeiro da empresa.

5.3. Análise de Produtos e Categorias

Identificação dos dez produtos com maior quantidade comercializada e comparação do faturamento gerado pelas diferentes categorias.

5.4. Análise Temporal

Investigação da evolução das vendas ao longo dos anos e meses, buscando identificar períodos de maior e menor faturamento e possíveis padrões de sazonalidade.

5.5. Desempenho dos Vendedores

Identificação dos cinco vendedores com maior faturamento, comparação dos resultados individuais e cálculo do ticket médio por produto vendido.

5.6. Preferências de Pagamento

Análise da utilização das diferentes formas de pagamento e cálculo da participação percentual de cada modalidade nas transações concluídas.

5.7. Análise Geográfica

Comparação do faturamento entre os estados presentes na base de dados, identificando os mercados com maior participação nos resultados da empresa.

5.8. Visualização dos Dados

Criação de gráficos para facilitar a interpretação dos resultados, identificar tendências e apresentar os principais indicadores de desempenho.

5.9. Estudo Estratégico

Desenvolvimento de uma investigação adicional, cruzando diferentes dimensões da base de dados para identificar oportunidades comerciais e propor estratégias de crescimento para a empresa.

6. Resultados e Conclusões

As análises realizadas permitem compreender melhor o comportamento das vendas, identificar os produtos e categorias de maior relevância financeira, avaliar o desempenho da equipe comercial e reconhecer os estados com maior participação no faturamento.

Com base nos resultados obtidos, o estudo busca fornecer informações que auxiliem a gestão na definição de estratégias comerciais, no direcionamento de campanhas de marketing e na identificação de oportunidades de expansão.


7. Considerações Finais

Este projeto proporcionou a aplicação prática dos conhecimentos de análise de dados utilizando Python, desde a preparação e limpeza das informações até a construção de indicadores e visualizações.

Além do desenvolvimento técnico, a atividade demonstra a importância de utilizar dados para compreender o desempenho de uma organização e apoiar decisões estratégicas fundamentadas em evidências.
